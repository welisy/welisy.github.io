Banco · crédito imobiliário Em produção

Agente de IA no WhatsApp para o pré-onboarding de crédito imobiliário

Problema

O banco queria que um agente de IA, hospedado pela consultoria parceira na AWS, acompanhasse clientes na fase de pré-onboarding do financiamento. Tinha que rodar no mesmo número de WhatsApp da operação e passar a conversa para um humano quando precisasse.

Solução

O CRM alimenta uma campanha no Evolux com os dados da proposta, que viram campos da conversa. A resposta do cliente cai num bot dedicado que chama um middleware em n8n. O n8n autentica no agente (OAuth client credentials), injeta o contexto da proposta na primeira mensagem e devolve as respostas de forma assíncrona pela API de conversas. Transferência para humano e encerramento são sinais do próprio agente.

  1. Salesforce
  2. Campanha Evolux
  3. Bot
  4. n8n + OAuth
  5. Agente de IA (AWS)
  6. API de conversas

Resultado

Cinco cenários testados ao vivo antes do go-live (campos, ordem de 8/8 mensagens, envio assíncrono, transbordo e encerramento). Em produção desde outubro de 2026, com CPF removido do tráfego e filtro de eco nas mensagens.

  • n8n
  • OAuth 2.0
  • REST
  • WhatsApp Business
  • Evolux CX
Bancos · qualidade Em produção

Avaliação de qualidade por IA em ligações e conversas de WhatsApp

Problema

Monitoria de qualidade manual cobre uma fração pequena dos atendimentos. Duas operações bancárias queriam avaliar ligações e conversas com IA, cada fila com o seu critério, sem ninguém subir arquivo à mão.

Solução

Pipelines em n8n capturam o fim de cada atendimento, filtram o que vale avaliar (mínimo de interação, sem mensagens de bot), agrupam por fila e enviam em lote para a API de análise com o critério certo. Na voz, a amostra prioriza detratores (NPS até 6 ou CSAT insatisfeito) e completa por sorteio até o limite diário de minutos. Os critérios são criados por API, com script idempotente.

  1. Webhook / relatório Evolux
  2. n8n: filtro + buffer
  3. Lotes por fila
  4. API de análise (IA)
  5. Painel de qualidade

Resultado

400+ conversas avaliadas nos quatro primeiros dias, sem falha de envio. Quando 144 avaliações falharam, separei duas causas (token de gravação errado e áudio ainda indisponível no envio) e entreguei ao time do produto um caso mínimo reproduzível.

  • n8n
  • Python
  • Multipart
  • Google Sheets
  • IA
Plano de saúde · dados Mensal

Relatório mensal de 330 mil disparos de WhatsApp

Problema

O relatório de status de guia enviado aos beneficiários vinha de um notebook que falhava todo mês: cookie expirado, linhas duplicadas ou faltando em volume alto e filtro de template quebrando a cada renomeação.

Solução

Reescrevi como uma CLI em Python. Login programático; coleta por janela de tempo adaptativa, que se subdivide até a fatia caber numa paginação rasa (o offset profundo da API era instável); descoberta automática dos templates do período; e enriquecimento paralelo (12 workers, cerca de 50 req/s, retomável) para recuperar o texto exato de cada mensagem.

  1. API Evolux
  2. Coleta adaptativa
  3. Enriquecimento paralelo
  4. Planilha consolidada

Resultado

175 mil registros de quinze dias coletados sem duplicidade. O relatório que quebrava todo mês passou a rodar de ponta a ponta com um comando.

  • Python
  • Concorrência
  • REST
  • XLSX
Banco · atendimento Em produção

Janela de 24h do WhatsApp: relatório e repescagem automática

Problema

Quando a operação não responde em 24 horas, a Meta fecha a janela e o atendimento só volta com template pago. Num único fim de semana, 102 conversas expiraram sem resposta.

Solução

Um classificador lê cada conversa a partir da última mensagem do cliente e marca o estado (expirada, em alerta, aberta, respondida), além de anexo, fora de horário e fim de semana. As expiradas viram lista de assinantes de uma campanha de repescagem, que roda como job no Google Cloud Run.

  1. API de conversas
  2. Classificador de janela
  3. Lista de repescagem
  4. Campanha com template

Resultado

Repescagem enviando sozinha desde outubro de 2026, com cerca de 1.400 clientes recontatados nas três primeiras semanas.

  • Python
  • Cloud Run
  • WhatsApp templates
  • Evolux CX
Governo estadual · voz Validado ponta a ponta

URA de agendamento da Carteira de Identidade Nacional

Problema

O cidadão precisava agendar a emissão da CIN pelo telefone, e o sistema do governo só era alcançável por rede privada.

Solução

A URA chama um orquestrador em n8n, que chama uma Lambda proxy em Python dentro da VPC, ligada ao gateway do governo por VPN. As respostas saem em formato plano, prontas para TTS, com no máximo três opções por menu ("digite 9 para mais") e erros de negócio em HTTP 200 para a URA sempre conseguir ler a mensagem.

  1. Cidadão (voz)
  2. URA Evolux
  3. n8n
  4. AWS Lambda (VPC)
  5. VPN
  6. API do governo

Resultado

Fluxo validado ponta a ponta, com cada retorno do governo registrado no n8n para diagnóstico rápido.

  • Evolux Studio
  • n8n
  • AWS Lambda
  • API Gateway
  • Python
Serviços · helpdesk Em produção

Protocolo automático no helpdesk a cada ligação atendida

Problema

Toda ligação atendida precisava virar ticket, com o CPF e o agente certos. Quando a cobrança transferia para o atendimento, saíam dois protocolos para a mesma chamada.

Solução

Um fluxo n8n escuta o evento de atendimento, interpreta as variáveis da URA, valida o CPF, ignora os agentes da cobrança, faz find-or-create do contato e abre o ticket no agente que recebeu. Na transferência assistida o CPF não vem no evento, então é buscado nos dados da chamada. Um controle por número de origem evita ticket duplicado.

  1. Ligação atendida
  2. Webhook Evolux
  3. n8n: regras + dedup
  4. Agidesk: contato + ticket

Resultado

Um protocolo por ligação, inclusive nas transferências.

  • n8n
  • JavaScript
  • Evolux Voz
  • Agidesk API
